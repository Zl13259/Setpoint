方法边界与 Score v0

客观量价研究，不读取持仓，不做账户级仓位核定，不把技术分包装成收益承诺。

因果时间合同

只使用截至 t 日收盘已完成的数据形成日K信号，最早在下一交易时段执行。盘中未完成K线不参与 Q。摆动低点必须有右侧K线确认，不能把信号回填到事后最低点。v11.1 的盘中突破预告仅做条件试算，不形成正式信号或前向样本；预估入场区、止损与目标在收盘后重新冻结。v14.0 唯一例外：盘中触发型超跌反弹允许用当日盘中报价合成虚拟K线实时触发，但须通过同一套七门、仅当日有效，且以收盘验票为最终口径（收盘未确认则作废，不计绩效）。

决策链

日线：数据质量 → 三通道 → 冻结交易几何 → Q / E → 开盘研究模型
盘中：盘前预案 → 新鲜报价 → 结构有效 → 连续价格确认＋量能节奏 → 现价净赔率＋可成交 → 首次触发留痕 → 独立前向结算
账户：风险预算÷止损幅度 → 环境／事件仓位折扣与账户红线人工复核

三通道

  • 超跌反弹：近15日出现超跌（RSI≤30 / Z≤-2 / 5日跌≥12%），随后有企稳证据（按事件期 ATR 峰值/收盘价比分级：≥4% 需3根企稳 bar、≥2% 需2根、低波动1根），并满足三种触发之一：收复前高、收复 MA5、或 v14.5 新增 RSI 恢复（事件日 RSI≤30 后回升至≥40 且收复事件日收盘，不要求站上 MA5）；超跌低点未失效。v14.0 起支持盘中实时触发：以当日盘中报价合成虚拟K线探测，触发即冻结几何，收盘验票为最终口径。
  • 趋势回踩：MA20/MA60 与斜率确认原趋势，回踩明确支撑后重新转强。
  • 突破确认：前20日基底与压力明确，价格、收盘位置和量能共同确认，RS 相对同市场参考基准计算（v13.3 起跑输基准时 RS 子项计 0，不给弱于大盘的突破送高分）。

交易几何

入场区、止损与目标由触发时的结构锚点固定，不随当前价格移动。净赔率显示口径默认整区最优（v13.5 起），现价口径为辅；1.5 是研究门槛（v14.5 起按通道分级：超跌反弹 1.2、突破与回踩 1.5），不是正期望的数学证明。目标与止损同时展示百分比和 ATR 距离（显式标注测量基准：现价／入场区下沿）；ATR 空间提示不是新增门槛，压力近时应降级或放弃，而非拉远目标。止损距离低于 0.8 ATR 展示"赔率虚高"警示（低于 0.5 ATR 仍为硬拒绝）。止损是计划价，不保证跳空或涨跌停时成交。

净赔率 = 目标净收益 ÷ 止损净损失
S = 0.60 × Q + 0.40 × E（只作同通道启发式基线）

硬门槛

数据不足或陈旧、通道未成立、结构失效、几何非法、净赔率不足、流动性不合格、疑似涨停不可成交，均不能被高分抵消。实际开盘与盘中入场另检查止损距离：低于0.5 ATR或高于2.5 ATR均拒绝执行，不移动结构止损。价格离开入场区只改变执行状态，不允许追价；环境状态单列，不乘入 Q/E/S。

信号生命周期与失效口径

等待期间任何完成日K收盘触及失效锚点即判"结构失效"，不再于破位日开盘补入场，取消全部剩余窗口；盘中报价低点穿透冻结止损时，开盘与盘中两个执行模型同步失效（v13.5 起统一口径，此前存在止损穿透后状态机不结算的漏洞）。开盘窗口耗尽只代表开盘价不合格，不自动否决独立盘中模型。v14.0：盘中触发的超跌信号以收盘验票为最终口径，验票作废的记录保留于盘中前向日志并标注"验票作废"，不计入结算绩效。

双执行模型与当日生命周期

开盘研究模型继续按实际开盘价检查，各通道均为 3 次开盘窗口（v14.5 起 2→3，给回踩留出时间），用于和既有历史回放保持可比。盘中执行模型独立运行：盘前不生成隔夜挂单；连续竞价时，报价新鲜度 A股≤180秒、美股≤1200秒（v14.3 独立阈值）；七门在信号年龄 ≤2 个交易日内开放，开盘模型判废当日即执行、不跨日排队，年龄 ≥1 日时价格须落在冻结入场区 ±1% 的漂移护栏内；超跌还须先测试入场区下沿后收复；至少2次连续区内有效报价，间隔30～3600秒且未走弱，同时当日量能节奏达到20日全日节奏基准的0.65倍（v14.3 自0.8放宽——均匀成交下原曲线全天仅 0.71~0.73，几乎只在尾盘放行；v14.0 起按分时量能曲线 t＋0.13·sin(πt) 估计应累计成交额，修正早盘线性外推失真）。报价新鲜度：A股≤180秒，美股≤1200秒（v14.3 独立阈值，覆盖免费行情延迟）。上述是盘中执行模型的待验证参数，不是已证明最优规则。开盘窗口耗尽不自动否决盘中模型，结构失效则两者都否决。盘中首次七门通过只记录一次，订单口径仅当日有效，收盘未触发自动作废。v14.0 新增盘中触发型超跌反弹：对阶段①/②的超跌结构，盘中按当前报价合成虚拟K线实时探测，触发即冻结几何并开放同一套七门（年龄按当日计、无漂移护栏、仅当日有效）；收盘后自动验票——当日完成K线仍满足超跌触发则转为正式信号进入前向结算，否则作废留痕、不计绩效。触发来源（日线预案/盘中实时）在盘中前向记录中分列统计。

成交后研究口径

T+1／3／5／10 均指入场后的对应交易日。策略实际固定期限在提前退出后锁定实际净R；反事实路径假设不退出，只用于研究止损后收复与目标后继续上涨。MFE／MAE 由日K高低价估计，同日先后不可知；首次触及日均以T+0为入场日。历史末端不足持有期的TIMEOUT属于右删失，不得当作已完成交易。

前向证据与版本簇

严格纯前向同时要求 recordOrigin=PRE_ENTRY、savedAt 存在、dataAsOf=triggerDate，并在同一策略版本与交易模型参数簇内按经济信号去重。扫描数量不属于交易模型参数；页面展示升级不重置策略簇，旧档案缺少策略版本时按 legacy:页面版本隔离。不同策略版本不混合计算绩效；全量跨版本档案只用于审计和导出。观察样本表展示模型成本／现价／浮动盈亏，仅为模型口径，不代表账户实际成交。

高周期压力

只使用触发日前已经完成的周线和月线摆动高点，当前未完成周/月不参与。若最近高周期压力位于原第一目标之前，则将第一目标收缩到该压力并重算净赔率；日线是否触发不由高周期压力反向改写。

验证边界

页面内回放是当前加载池上的探索性研究，不含完整历史股票池、退市样本、滚动样本外、净化隔离和多重试验校正；也未建立组合级并发持仓、资金占用或权益曲线。停牌缺口与逐笔流动性无法由日K完整还原，一字跌停只是保守成交约束，不等于完整市场冲击模型。样本少于30笔显示“样本不足”；达到30笔也不自动等于稳定规律。回放与 v10.2 起新建前向记录覆盖原信号有效期内的回区开盘；旧前向记录仍按原单次口径结算，不混写。

交易日一致性

参考基准先并行核验多源完成日K与报价交易日，采用可佐证的最新完成日；多源冲突无法裁决或市场级陈旧时，整市场停止生成信号。个股最近完成日K必须与该基准一致，不一致时继续降级数据源，仍不一致则列为数据异常。缓存同样接受交易日复核，不以旧基准反向锁死新数据。

规则插件契约（v13.0 起）

quant-rules.js 掌管 DEFAULTS、三通道参数、排除名单与页面/策略版本；window.QuantRules 数组承载插件规则，按 RULE_MANIFEST 登记顺序在触发判定时执行：gates(ctx) 返回 true 通过、返回字符串即否决（记入拒绝原因，不可由高分或价格抵消）；scoreAdjust(q, ctx) 对 Q 做有界加减（0~100）；params 为预留声明。ctx 含 channel/code/market/config/metrics/geometry/features/Q。规则文件缺载、契约不符或 id 重复时页面红字告警并停止启动；规则执行异常按否决处理，appliedRules/ruleGate 随信号留痕。回放 Worker 使用同一套 rules＋core＋插件规则，实时与回放口径一致。
